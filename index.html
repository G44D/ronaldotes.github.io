Foto jadi kepala 3D

Satu foto wajah → tekstur wajah + warna rambut pada kepala format CR7 → unduh GLB. Foto diproses di perangkatmu.

1. Pilih foto

2. Analisis Grok AI (opsional)

Grok membaca foto untuk warna rambut, gaya rambut, dan jenggot. Tanpa kunci, warna rambut diambil langsung dari piksel foto.
Untuk website publik, arahkan Endpoint ke proxy servermu agar API key tidak terlihat pengunjung.

3. Cocokkan jaring dengan wajah

4. Terapkan dan unduh
